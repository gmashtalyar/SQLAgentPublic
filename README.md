## 💡 Что такое SQL Agent?

**SQL Agent** — это современный AI-инструмент, который устраняет барьер между вами и вашими базами данных. Забудьте о необходимости держать в голове сложные команды, джойны и особенности диалектов. Просто сформулируйте вопрос на человеческом языке — например, *«Покажи топ-10 клиентов по сумме покупок за прошлый месяц»* — и ассистент мгновенно сгенерирует точный, оптимизированный SQL-запрос и вернет готовый результат.

SQL Agent доступен сразу в двух удобных форматах:
1. 🌐 **Веб-приложение (Web App / Web Workspace)** — для полноценной визуальной работы в любом браузере без установки программ.
2. 💻 **Консольное приложение (CLI App)** — для быстрой и автономной работы прямо в терминале вашей операционной системы.

### 🌐 1. Веб-приложение (Web Workspace)
*Работайте с данными из любого браузера — без установки и сложных настроек.*

- **Мгновенный старт**: откройте сайт на любом компьютере и сразу приступайте к анализу.
- **Интерактивный навигатор по схеме**: наглядный просмотр структуры базы данных, таблиц, типов полей и связей.
- **История и закладки**: сохраняйте удачные запросы и возвращайтесь к ним в один клик.
- **Удобный экспорт**: скачивайте результаты выборок в форматах CSV, JSON или Excel (XLSX) для отчетов и презентаций.
- **Гибкость AI**: используйте встроенные облачные AI-модели или подключите собственный ключ.

### 💻 2. Консольное приложение (CLI App)
*Легковесная утилита для разработчиков, DevOps и тех, кто ценит скорость терминала.*

- **Максимальная приватность**: учетные данные и строка подключения хранятся исключительно на вашем локальном компьютере в зашифрованном виде.
- **Полная автономность**: поддержка локальных моделей через Ollama позволяет работать полностью изолированно, без отправки данных во внешние сети.
- **Удобное управление подключениями**: быстрое переключение между серверами разработки, тестовыми и рабочими базами через сохраненные профили.
- **Кроссплатформенность**: готовые установщики для Windows, macOS и Linux.

## 🚀 Почему выбирают SQL Agent?

### 🗣️ Запросы на естественном языке
Больше не нужно вспоминать, как правильно объединить пять таблиц через `LEFT JOIN` или составить группировку с оконной функцией. Опишите задачу своими словами — SQL Agent поймет смысл, учтет связи между таблицами и сформирует оптимальный запрос.

### 🛡️ Безопасность из коробки (Safe by Default)
Безопасность ваших данных — ключевой приоритет:
- **Режим «только чтение» по умолчанию**: система защищена от случайного изменения или удаления записей.
- **Защита от деструктивных действий**: встроенная проверка надежно блокирует опасные команды (такие как `DROP`, `TRUNCATE` и неконтролируемые операции).
- **Контроль выполнения**: система запрашивает подтверждение перед выполнением тяжелых операций и предупреждает о неоптимальных запросах.

### 🗄️ Поддержка ключевых СУБД
Работайте с популярными реляционными базами данных в едином интерфейсе:
- **PostgreSQL** — включая поддержку сложных типов, JSON, аналитических функций и CTE.
- **MySQL и MariaDB** — полная совместимость с оптимизацией под синтаксис MySQL.
- **SQLite** — прямое подключение к локальным файлам баз данных без поднятия серверов.

## 🎯 Реальные сценарии применения

- **Бизнес-аналитика**: вычисление retention по когортам, подсчет среднего чека, динамика конверсий и определение наиболее прибыльных сегментов аудитории.
- **Аудит качества данных**: мгновенный поиск пустых значений, битых записей, пользователей без заказов или аномальных транзакций.
- **Оперативная отчетность**: быстрая подготовка срезов данных для руководства и маркетинга с выгрузкой в Excel за несколько секунд.
- **Исследование незнакомых проектов**: моментальное понимание того, какие таблицы и поля содержатся в базе, и как они связаны между собой.
